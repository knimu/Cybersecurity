# 🛡️ Hack The Box (HTB) Learning Journey

Welcome to my **Hack The Box (HTB)** learning repository.

This folder documents my progress through Hack The Box labs as I build practical skills in **Cybersecurity**, **Network Security**, and **Ethical Hacking**. Every machine helps me understand how attackers discover vulnerabilities and how security professionals identify and mitigate them.

The purpose of this repository is to:

* Practice hands-on cybersecurity skills
* Document what I learn from each machine
* Revise important concepts and commands
* Build a portfolio of practical learning

---

# 📚 Learning Methodology

For every HTB machine, I follow a structured approach:

1. Enumeration
2. Service Identification
3. Vulnerability Analysis
4. Exploitation (within the HTB lab environment)
5. Learning & Documentation

Rather than simply collecting flags, I focus on understanding:

* Why each command works
* What each service does
* How vulnerabilities are identified
* How similar attacks can be prevented
